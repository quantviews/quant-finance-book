Две пары по 80 минут, глава 5 книги. Старт проекта 1 «Фундаментальный анализ отрасли».

- Первая пара: короткое письменное задание по главе 4 (проверяет преподаватель); лекция: отчётность юрлица и группы, ГИР БО и RFSD, эмитенты акций курса в RFSD, формы и коды строк, единицы и знаки, формат parquet и CSV, pandas и Polars, полный RFSD (с Hugging Face или скачанным файлом), ОКВЭД (с демо классификатора [rustata](https://rustata.ru/classifier/okved2)), финансовые коэффициенты, медиана и среднее, EBITDA, качество данных, скрытая отчётность, охват по Росстату; проект 1.
- Вторая пара: практика на выборке книги – задания 1–5 ноутбука.
- Дома – старт проекта 1: кандидаты в тему по полному RFSD (задание 6), код ИИ-ассистента (7), заявка на тему (8).

Презентация – 35 слайдов.

## Материалы для студентов

- `lecture.html` – презентация (копия `_slides/index.html`), работает без сети.
- `practice-04.ipynb` – ноутбук практики: задания 0–5 на занятии, 6–8 дома. Без ответов и результатов выполнения. Задание 6 скачивает файл полного RFSD за 2025 г. (534 МБ, версия закреплена по коммиту Hugging Face) или читает его по `hf://`; из российских сетей Hugging Face может не отвечать – тогда Colab.
- `data/issuers_2018_2025.csv` – отчётность головных компаний-эмитентов 25 акций курса (и SBER) за 2018–2025 гг. из полного RFSD: флаги и основные строки, тыс. руб.
- `data/metadata.json` – описание и контрольные суммы.

Выборку RFSD ноутбук берёт из данных книги (`data/rfsd_sample.parquet`) по закреплённому коммиту, CSV эмитентов – из этой папки на GitHub (ветка `main`); обе загрузки сверяются по SHA256. Без сети файлы читаются из папки `data` рядом с ноутбуком. **Перед раздачей CSV нужно запушить.**

Класс ОКВЭД для практики назначается по тикеру: по кругу в алфавитном порядке тикеров (таблица – в начале ноутбука), по 5 студентов на класс.

## Особенности данных

- ИНН – головная компания-эмитент (ПАО): это отчётность одного юрлица по РСБУ, не группы.
- SBER, SBERP и BSPB (банки) и MOEX в RFSD нет: отчитываются перед Банком России.
- Отчётность многих эмитентов скрыта; до 2019 г. RFSD опирается на данные Росстата, поэтому у части эмитентов раскрыт только 2018 г.

## Сборка

Из корня книги:

```bash
# 1. Только автор курса: эмитенты из локальной копии полного RFSD (проект ../rfsd, RFSD_DATA_ROOT)
python lessons/04-accounting-data/export_issuers.py
# 2. CSV эмитентов, графики, слайды с расчётами (_lecture.qmd) и ноутбук
python lessons/04-accounting-data/build_materials.py
# 3. Презентация
cd lessons/04-accounting-data && quarto render intro.qmd && cp _slides/index.html lecture.html
```

Числа на слайдах вычисляются из снимка книги и CSV эмитентов. Скрипт заново создаёт студенческий ноутбук – не запускайте его поверх выполненной работы.

Сценарий преподавателя, задание на бумаге, ведомость, решения и ключ ответов лежат в приватной папке `quant-finance-teaching`, вне репозитория.
