# Третье занятие: 19 ноября 2026 – финансовые данные, доходность и риск

Две пары по 80 минут, главы 2–4 книги. Лекции по финансовым данным на втором занятии не было (самостоятельная работа), поэтому лекция третьего занятия начинается с этой темы.

- Первая пара: короткое письменное задание по самостоятельной работе 2; финансовые данные (источники, ISS, корпоративные действия, ошибка выжившего, качество данных); макроданные – инфляция и курс рубля из [rustata](https://rustata.ru); начало темы «Доходность».
- Вторая пара: риск (волатильность, хвосты, просадки, коэффициент Шарпа) и практика на своей акции: задания 1–4 и 7. Задания 5–6, 8–9 – дома.

Презентация – 42 слайда.

Каждый студент продолжает работать с акцией из самостоятельной работы 2 ([таблица распределения](https://docs.google.com/spreadsheets/d/1jDm3lILAcKnvIehthge5Q3NfrHSzqmem/edit?usp=sharing)) и отвечает на вопрос: стоило ли держать её вместо индекса MCFTR или денежного рынка?

## Материалы для студентов

- `lecture.html` – презентация (копия `_slides/index.html`), работает без сети.
- `practice-03.ipynb` – ноутбук практики: задания 0–4 и 7 на занятии, 5–6 и 8–9 дома. Без ответов и результатов выполнения.
- `data/prices_2015_2026.csv` – снимок занятия: 26 акций (`adj_close` и `close`), IMOEX, MCFTR и расчётный индекс денежного рынка RUONIA, 05.01.2015–16.11.2026.
- `data/metadata.json` – поля, особенности и контрольная сумма CSV.

Ноутбук загружает CSV с GitHub (`raw.githubusercontent.com`, ветка `main`) и сверяет SHA256. Без сети он читает `data/prices_2015_2026.csv` рядом с собой. **Перед раздачей CSV нужно запушить**, иначе проверка суммы не пройдёт.

## Особенности снимка

- SIBN нет в хранилище moexutils: история загружена из ISS и скорректирована на дивиденды тем же методом moexutils, без записи в хранилище.
- GMKN, PLZL, TRNFP: дивиденды до сплита в проекте dividends записаны в расчёте на акцию после сплита, а `moexutils.adj_close` делит их на сырую цену до сплита и почти не учитывает. В `export_source.py` для этих бумаг `adj_close` пересчитан от цены, скорректированной на сплит. Та же ошибка есть в базовом снимке книги `data/stocks.parquet`.
- PIKK: торгов нет с 16.10.2026, последняя цена 15.10.2026.
- MCFTR за 24.03.2022 в ISS не опубликован, пропуск оставлен. 07.01.2022 исключено: значение IMOEX есть, торгов акциями не было.

## Макроданные для слайдов

ИПЦ (ЕМИСС 31074, Россия, все товары и услуги, к предыдущему месяцу) и официальный курс доллара Банка России загружены из API rustata (`export_macro.py`, нужен токен `RUSTATA_TOKEN` в `.env`) и сохранены в `data/cpi-source.parquet`, `data/usdrub-source.parquet`, `data/macro-source.json`. Студентам эти файлы не нужны: макроданные есть только на слайдах. Пример консолидации ВТБ и расчёт ошибки выжившего берутся из снимка книги (`data/stocks_raw.parquet`, `qf.data`).

## Сборка

Из корня книги:

```bash
# 1. Только автор курса: выгрузка из moexutils (нужен MOEX_DATA_ROOT)
python lessons/03-returns-risk/export_source.py
# 1а. Только автор курса: инфляция и курс из rustata (нужен RUSTATA_TOKEN)
python lessons/03-returns-risk/export_macro.py
# 2. CSV, графики, слайды о доходности и риске (_lecture.qmd) и ноутбук
python lessons/03-returns-risk/build_materials.py
# 2а. Слайды о финансовых данных и макроданных (_data.qmd), после шага 2
python lessons/03-returns-risk/build_data_slides.py
# 3. Презентация
cd lessons/03-returns-risk && quarto render intro.qmd && cp _slides/index.html lecture.html
```

Числа на слайдах не вписаны вручную: `build_materials.py` вычисляет их по тому же CSV, что получают студенты, и записывает в `_lecture.qmd`; `build_data_slides.py` записывает блок данных в `_data.qmd`. Скрипт заново создаёт студенческий ноутбук, не запускайте его поверх выполненной работы. Ссылку на форму сдачи можно вписать в `FORM_URL` и пересобрать.

Сценарий преподавателя, задание на бумаге, ключ ответов по всем акциям и решения лежат в приватной папке `quant-finance-teaching`, вне репозитория.
