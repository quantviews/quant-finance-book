# Первое занятие: 5 ноября 2026

Две пары по 80 минут: вводная лекция и первая практика. В конце первой пары открываем ноутбук и проверяем таблицу; во второй строим график, считаем и обсуждаем результаты. Презентация содержит 24 слайда.

## Материалы для студентов

- `intro.qmd` – презентация Reveal.js, оформление объединяет шрифт IBM Plex Sans из книги (в презентации он используется и для основного текста), палитру её графиков и тёмно-синий цвет с логотипом ВШЭ. Вертикальные цветные полосы слева не используются.
- `practice-01.ipynb` – ноутбук с примерами и заданиями, без ответов и сохранённых результатов выполнения.
- `data/prices_2021_2026.csv` – отдельная копия тех же данных.
- `data/metadata.json` – период, поля и контрольная сумма CSV.

Ноутбук загружает CSV по ссылке из этого репозитория (`raw.githubusercontent.com`, ветка `main`) и сверяет контрольную сумму. Без сети он читает `data/prices_2021_2026.csv` рядом с собой, поэтому файл данных входит в архив занятия. После пересборки данных новый CSV нужно запушить до раздачи ноутбука, иначе проверка суммы не пройдёт. Для вычислений нужны pandas и matplotlib, для локального запуска также Jupyter. В Google Colab загрузите `.ipynb` и выполните ячейки сверху вниз. Никаких API, ключей или загрузки всего репозитория не требуется.

Источники: отдельный снимок занятия, выгруженный из moexutils 05.11.2026, подготовленный из данных Московской биржи и дивидендных корректировок. В файле только SBER и LKOH за 04.01.2021–03.11.2026 (2026 год неполный). Скорректированные уровни не являются ценами исторических сделок. Налогов, комиссий и точных дат зачисления дивидендов в расчётах нет.

## Сборка презентации

Из этой папки:

```bash
quarto render intro.qmd
```

Готовый файл: `_slides/index.html`. Ресурсы встроены в HTML, его можно открыть в браузере без сети. Клавиши: стрелки – смена слайда, `F` – полный экран, `Esc` – обзор. Внешняя ссылка на книгу требует сети.

Для пересборки материалов из сохранённого снимка занятия (`data/stocks-source.parquet`, происхождение в `data/source.json`) из корня книги:

```bash
python lessons/01-introduction/build_materials.py
```

Эта команда заново создаёт студенческий ноутбук. Не используйте её для файла с выполненной студенческой работой.

## Разделение материалов

Сценарий преподавателя, решения и критерии находятся в отдельной приватной папке `quant-finance-teaching`, вне репозитория книги. Они не включаются в HTML, заметки слайдов, ноутбук студентов или архив для раздачи.

Публикация и коммит не выполняются автоматически. Для раздачи до публикации достаточно HTML и `.ipynb`; офлайн можно использовать CSV и статический график из `figures/`.

При следующем обновлении сначала выгрузите SBER и LKOH из `moexutils.stocks.read_stocks` (поля date, ticker, close, adj_close; split_adjusted=True), сохраните в `data/stocks-source.parquet` и обновите `data/source.json`. Скрипт сборки сам не обращается к хранилищу. Базовый снимок всей книги не меняется.
