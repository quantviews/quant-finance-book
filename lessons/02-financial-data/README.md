# Второе занятие: 12 ноября 2026 – самостоятельная работа

Очного занятия нет. Студенты работают сами 80 + 80 минут по ноутбуку [practice-02-data.ipynb](practice-02-data.ipynb).

Тема – финансовые данные (главы 2 и 3 книги). Студенты сами загружают историю торгов с Московской биржи и проверяют её:

- карточка бумаги, режимы торгов, основной режим;
- постраничная выдача ISS и функция загрузки всей истории;
- паспорт данных: даты, строки без цены, сверка с календарём индекса IMOEX;
- консолидация акций ВТБ в июле 2024 г. и корректировка ряда;
- дивидендный разрыв Сбербанка 18.07.2025;
- три самых больших движения своей акции и их объяснение;
- вывод на 150–250 слов и проверка кода, написанного ИИ-ассистентом.

Доходность и риск не считаются: это тема следующих занятий.

## Как запускать

Google Colab: загрузить `.ipynb` и выполнять ячейки сверху вниз. Локально: Jupyter с pandas, matplotlib и requests. Данные приходят с ISS Московской биржи (`iss.moex.com`) без ключей и регистрации, поэтому нужна сеть. Файлов данных в папке нет: загрузить и проверить их – часть задания.

Каждый студент выбирает одну акцию из списка в задании 1, поэтому ответы на задания 1–4 и 7 у всех разные.

## Сборка

Из корня книги:

```bash
python lessons/02-financial-data/build_notebook.py
```

Скрипт заново создаёт пустой студенческий ноутбук. Не запускайте его поверх выполненной работы.

Решения и ключ для преподавателя хранятся в приватной папке `quant-finance-teaching`, вне репозитория книги.
