# Данные к книге «Количественные финансы»

Все примеры в книге работают на этих файлах, поэтому результаты воспроизводятся
без доступа к платным источникам и без повторной загрузки с биржи.
Читать их удобнее всего через модуль `qf` из корня книги:

```python
from qf import data
prices = data.load_stocks(["SBER", "GAZP"], start="2015-01-01")
```

В R – функции из `R/qf.R` (`qf_load_stocks()` и др.).

## Базовый снимок (`data/`)

| Файл | Что внутри |
|---|---|
| `stocks.parquet` | 94 акции MOEX (в том числе снятые с торгов), дневные данные с 2003 г. Цены приведены к текущей базе с учётом сплитов, истории переименованных бумаг склеены. `adj_close` – цена с поправкой на дивиденды и сплиты (для расчёта полной доходности), `market_cap` – капитализация, руб. |
| `stocks_raw.parquet` | Сырые цены ISS по бумагам со сплитами и переименованиями (GMKN, TRNFP, VTBR, T/TCSG, YDEX/YNDX и др.) – для упражнений по подготовке данных |
| `indexes.parquet` | Индексы MOEX: IMOEX, MCFTR (полной доходности), RTSI, облигационные RGBI, RGBITR, RUCBTRNS, отраслевые |
| `dividends.parquet` | История дивидендов: дата закрытия реестра, год, период, размер на акцию |
| `key_rate.parquet` | Ключевая ставка Банка России (даты изменений) |
| `ruonia.parquet` | Ставка RUONIA |
| `zcyc.parquet` | Кривая бескупонной доходности ОФЗ (КБД) Московской биржи |
| `sectors.csv` | Отраслевая принадлежность акций |
| `splits.csv`, `renames.csv`, `delisted.csv` | Справочники корпоративных событий: сплиты, переименования, снятые с торгов бумаги |
| `snapshot.json` | Дата выгрузки снимка |



## Отчётность компаний (RFSD) и статистика Росстата

| Файл | Что внутри |
|---|---|
| `rfsd_sample.parquet` | Выборка RFSD 2018–2025: компании классов ОКВЭД 10, 41, 47, 49, 62 с выручкой от 1 млрд руб. хотя бы в одном году; основные строки форм (тыс. руб., расходы отрицательные) и названия (`name`) |
| `rfsd_summary.parquet` | Сводка по полному RFSD по годам: число организаций, поданных отчётов, проблемы качества |
| `rfsd_cases.parquet` | Отчётность нескольких известных компаний за все годы (примеры в тексте) |
| `rfsd_revenue_okved.parquet` | Суммарная выручка поданных отчётов полного RFSD по годам и классам ОКВЭД |
| `rfsd_hidden.parquet`, `rfsd_hidden_top.parquet` | Крупные компании, не раскрывшие отчётность: по годам и крупнейшие в последнем году |
| `okved.csv`, `rfsd_lines.csv` | Классификатор ОКВЭД 2 и справочник строк отчётности |
| `rfsd_snapshot.json` | Версия RFSD и параметры выборки |
| `rosstat_revenue.parquet` | Выручка организаций по классам ОКВЭД по данным Росстата (rustata, набор `showdata/indicator_278140`), тыс. руб. |

Файлы RFSD собираются в соседнем проекте `rfsd` (`python -m rfsd.export data`), ряд Росстата –
скриптом `scripts/build_rosstat.py` (нужен токен `RUSTATA_TOKEN`).

## Микроструктура рынка (`micro/`)

Производные данные журнала заявок Московской биржи к главе 17 (сам журнал не распространяется).
Читаются функцией `data.load_micro(name)`, в R – `qf_load_micro(name)`; собираются
скриптом `scripts/build_micro.py` из проекта RL.

| Файл | Что внутри |
|---|---|
| `sber_book.parquet` | SBER, 30.12.2025, 10:00–18:40: пять лучших уровней стакана на сетке 1 с |
| `sber_trades.parquet` | Сделки SBER за ту же сессию со знаком агрессора |
| `panel_5s.parquet` | Панель 60 акций, 5 732 тикер-дня 2021–2025 гг.: спреды, дисперсионные отношения, автокорреляции, OFI R² |
| `price_variable.parquet`, `net_edge.parquet` | Разложение дисперсии микроцены; торговая проверка правила на дисбалансе потока заявок |
| `universe.csv`, `ofi_horizon.csv`, `vr_monthly.csv` | Состав выборки, OFI R² по горизонтам, месячный ряд \|VR(5) − 1\| |

Панель и таблицы – из репликационного пакета статьи «Больше розницы, не меньше эффективности»
(https://github.com/quantviews/efficiency-paper-2026), лицензия CC BY 4.0 (`micro/LICENSE-data`).

## Полная история рынка акций (отдельный архив)

Все бумаги рынка акций Московской биржи с 1997 г. (≈2,5 тыс. бумаг, все режимы торгов,
все поля ISS), разбиты по годам: `shares/year=YYYY/part-0.parquet`.
Распакуйте архив в любую папку и укажите её в переменной окружения `QF_FULL_DATA`
либо положите в `_data_full/` рядом с книгой:

```python
shares = data.load_shares_full(start="2020-01-01", board="TQBR")
```

## Источники и условия

Московская биржа (ISS), Банк России (ключевая ставка, RUONIA), закрытияреестров.рф (дивиденды),
RFSD (Bondarkov et al., 2025; CC BY 4.0), Росстат через rustata.ru.
Данные предназначены для учебных целей. Снимок собран скриптом `scripts/build_data.py`.


## Практикум по облигациям (глава 13)

Отдельный снимок `bonds/` на **30.09.2026**, независимый от основного снимка акций.
Четыре ОФЗ-ПД: SU26232RMFS7, SU26236RMFS8, SU26243RMFS4, SU26238RMFS4.

| Файл | Содержание |
|---|---|
| `bonds/quotes.parquet` | Котировки TQOB с 2024 года до даты оценки; чистая цена в % номинала, НКД и номинал в рублях, биржевые доходность и дюрация |
| `bonds/coupons.parquet` | Даты и суммы известных купонов, начало периода и дата фиксации владельцев |
| `bonds/principal.parquet` | Погашение номинала, один платёж на выпуск |
| `bonds/curve.parquet` | КБД на дату оценки, годовые эффективные спот-ставки в процентах |
| `bonds/snapshot.json` | Номер и время снимка DuckLake, соглашения, SHA-256 файлов и расчётного модуля |

Чтение: `qf.data.load_bonds`, `load_bond_coupons`, `load_bond_principal`, `load_bond_curve`.
`qf.data.verify_bond_snapshot()` проверяет целостность данных и кода.
`qf/bonds.py` — точная автономная копия проверенного модуля из moex-analytics,
синхронизируемая авторским `scripts/build_bond_data.py`; установка moexutils или
moex-analytics читателям не нужна. Основной `scripts/build_data.py` этот снимок не меняет.

Расчёт на дату котировки (учебная T+0-модель), годовая эффективная доходность,
ACT/365F. НКД берётся из ISS. График будущих фиксированных выплат известен на момент
выгрузки, а не является архивом всех исторических версий раскрытия.

Источник: [Московская биржа](https://www.moex.com/ru/indices), MOEX ISS через moexutils.
