# Количественные финансы

Учебник по количественным методам анализа финансовых данных на примерах российского рынка.
Основной язык – Python, в ключевых примерах онлайн-версии есть код на R.

- **Онлайн-версия:** <https://quantviews.github.io/quant-finance-book/>
- **PDF:** <https://quantviews.github.io/quant-finance-book/quant-finance-book.pdf>
- **Автор:** Марсель Салихов ([сайт](https://quantviews.github.io/))

Книга написана к курсу «Количественные финансы» факультета мировой экономики и мировой политики
НИУ ВШЭ и подходит для самостоятельного изучения.

## Содержание

| Часть | Главы |
|---|---|
| I. Данные и инструменты | источники финансовых данных, подготовка данных, доходность и риск |
| II. Корпоративная отчётность | отчётность российских компаний (RFSD), отраслевой анализ |
| III. Временные ряды | модели ARMA, волатильность (GARCH), прогнозирование и машинное обучение |
| IV. Риск и портфели | VaR и Expected Shortfall, портфельная теория, CAPM и факторные модели |
| V. Долговой рынок | облигации, кредитный риск |
| VI. Торговые стратегии | бэктестинг и переобучение, моментум, микроструктура рынка |

Книга пишется: готовые главы и заготовки отмечены в оглавлении онлайн-версии.

## Как запускать примеры

Все примеры работают на снимке данных из папки `data/` и дают те же результаты, что в тексте.

```bash
git clone https://github.com/quantviews/quant-finance-book.git
cd quant-finance-book
pip install -r requirements.txt
```

Данные загружаются модулем `qf` из корня книги:

```python
from qf import data

prices = data.load_prices(["SBER", "GAZP"], start="2020-01-01")   # цены с поправкой на дивиденды
imoex = data.load_index("IMOEX")
```

В R – функции из `R/qf.R` (`qf_load_stocks()`, `qf_load_index()` и др.). Состав данных описан
в [data/README.md](data/README.md).

### Данные

| Что | Где |
|---|---|
| Снимок данных книги: около 100 акций Мосбиржи с 2003 г., индексы, дивиденды, ключевая ставка, RUONIA, кривая ОФЗ | `data/` (в репозитории) |
| Полная история рынка акций Мосбиржи с 1997 г. (≈2,5 тыс. бумаг) | отдельный архив; путь задаётся переменной `QF_FULL_DATA` |
| Российская макроэкономическая статистика | [rustata.ru](https://rustata.ru), API по бесплатному токену |

Источники: Московская биржа (ISS), Банк России, закрытияреестров.рф, Росстат. Снимок собирается
скриптом `scripts/build_data.py` из хранилища пакета `moexutils`; читателям книги этот шаг не нужен.

### Токены и другие секреты

Некоторые примеры обращаются к API, которым нужен токен (например, rustata). Токены хранятся в файле
`.env` в корне книги – он не попадает в git:

```bash
cp .env.example .env    # и впишите значения
```

```python
from qf import secrets
token = secrets.get("RUSTATA_TOKEN")    # из переменной окружения или из .env
```

## Как собрать книгу

Нужны [Quarto](https://quarto.org) 1.10+, Python с пакетами из `requirements.txt` и R
(для R-вкладок и выполнения кода через knitr: пакеты `reticulate`, `dplyr`, `tidyr`, `ggplot2`,
`nanoparquet`, `zoo`, `scales`, `jsonlite`, `systemfonts`).

```bash
quarto render                    # HTML и PDF в _book/
quarto render --to html          # только сайт
quarto render --to typst         # только PDF
quarto preview                   # сайт с автообновлением
quarto publish gh-pages          # публикация на GitHub Pages
```

Python-чанки выполняются через `reticulate` в conda-окружении `py312` (см. `_common.R`).
Результаты вычислений кэшируются в `_freeze/`: код главы перевыполняется только при изменении её
исходника.

PDF собирается через Typst по собственному шаблону учебника (`styles/typst/`), шрифты – в `fonts/`
(STIX Two, IBM Plex Sans, JetBrains Mono; все под лицензией OFL).

## Структура репозитория

```
*.qmd              главы книги
_quarto.yml        оглавление и настройки сборки
_common.R          общие настройки глав (knitr, reticulate, графики)
qf/                модуль Python: данные (data), стиль графиков (plot), секреты (secrets)
R/qf.R             загрузка данных в R
data/              снимок данных книги
scripts/           сборка снимка данных
styles/            оформление HTML и PDF
fonts/             шрифты
_freeze/           кэш результатов вычислений
```
